# 등록 야영장 검색

등록 야영장 이름으로 상대 검색 관심도를 찾는 정적 페이지입니다.

https://kimyounil1.github.io/camping-search/

관심도는 망상오토캠핑리조트 = 1입니다. 기간은 2025-10-01부터 2026-09-30까지이고, 조회일은 2026-10-21입니다. 등록부는 공공데이터포털 data.go.kr 15037499, 파일 2026-09-23입니다.

시설과 업종은 한국관광공사 고캠핑 정보 조회서비스, data.go.kr 15101933, 2026-10-21 조회입니다. 조회 서비스에 없는 이름은 고캠핑 웹사이트 캠핑장 안내에서 같은 날 보완했습니다. 개별 화장실 추정은 네이버 장소 태그가 아니고, 확인된 개별 화장실도 아닙니다.

## 네이버 리뷰 데이터 최신화

각 캠핑장의 네이버 플레이스 리뷰 수(방문자 리뷰 및 블로그 리뷰)를 최신화할 수 있습니다.

### 방법 1: GitHub Actions로 원클릭 최신화 (권장)
1. GitHub 저장소의 **Actions** 탭으로 이동
2. 좌측 워크플로우 목록에서 **Update Naver Reviews** 선택
3. 우측 **Run workflow** 버튼 클릭 → 클라우드 러너가 자동으로 크롤링 후 최신 JSON 커밋/배포

### 방법 2: 로컬 스크립트 실행
```bash
# 기본 실행 (기존 항목 스킵 후 이어하기)
python3 scripts/update_naver_reviews.py

# 강제 전체 덮어쓰기 최신화
python3 scripts/update_naver_reviews.py --force
```
