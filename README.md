# 등록 야영장 검색

등록 야영장 이름으로 상대 검색 관심도를 찾는 정적 페이지입니다.

https://kimyounil1.github.io/camping-search/

관심도는 망상오토캠핑리조트 = 1입니다. 기간은 2025-10-01부터 2026-09-30까지이고, 조회일은 2026-10-21입니다. 등록부는 공공데이터포털 data.go.kr 15037499, 파일 2026-09-23입니다.

시설과 업종은 한국관광공사 고캠핑 정보 조회서비스, data.go.kr 15101933, 2026-10-21 조회입니다. 개별 화장실 추정은 네이버 장소 태그가 아니고, 확인된 개별 화장실도 아닙니다.
